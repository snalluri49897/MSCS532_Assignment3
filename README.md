# Assignment 3: Algorithm Efficiency and Scalability

## Files

- `randomized_quicksort.py` – Implements Randomized Quicksort and compares it with Deterministic Quicksort.
- `hash_table_chaining.py` – Implements a Hash Table using Separate Chaining.

## Requirements

- Python 3.x

## Run Instructions

### Randomized Quicksort Benchmark

```bash
python randomized_quicksort.py
```

This executes the benchmark on random, sorted, reverse-sorted, and repeated-element arrays.

### Hash Table with Chaining

```bash
python hash_table_chaining.py
```

This demonstrates insert, search, delete, and display operations on the hash table.
